Cadastre uma linha por subtópico. Para um tópico sem divisão, deixe o campo Subtópico em branco. As alterações são salvas no navegador e sincronizadas com o Supabase quando a conta estiver conectada.

Configurações do aplicativo

Chaves, autenticação e sincronização. Essas opções ficam separadas das atividades de estudo.

IA (Gemini)

A análise de edital usa a IA pelo servidor do aplicativo, com a sua conta. Não é preciso informar nenhuma chave neste navegador.

A chave do Gemini fica guardada como segredo no servidor (Supabase) e nunca é enviada ao navegador. O uso tem limite diário por conta.

Sincronização com Supabase

Use o projeto Supabase Nutri já compartilhado com seus outros aplicativos. Não é necessário criar outro projeto.

Use o projeto existente. O teste verifica se a API responde; o login habilita a leitura/gravação dos dados do usuário.

Conexão tradicional com Supabase

Use URL do projeto + chave pública + e-mail e senha. Esta é a forma convencional; não exige OAuth.

Não conectado

Salvamento local automático + sincronização com a nuvem

As alterações são gravadas primeiro neste dispositivo e, quando conectado, enviadas à nuvem após uma breve pausa.

Sincronização manual e recuperação (avançado)

Use estas opções apenas quando precisar comparar ou recuperar dados. O envio mescla concursos e não deve ser usado para substituir deliberadamente a nuvem sem conferir o conteúdo local.

Opção alternativa: entrar com Google (OAuth)

O login por Google é opcional e exige configuração adicional no painel Supabase. A conexão tradicional acima continua disponível sem essa configuração.

Para habilitar essa opção: Authentication → Sign In / Providers → Google; depois configure a URL de retorno. Se você usa o HTML diretamente no computador (file://), prefira a conexão tradicional com e-mail e senha.

Como conectar: 1) Informe a URL e a chave pública do projeto Nutri. 2) Clique em Guardar configuração. 3) Digite o e-mail e a senha da conta do aplicativo e clique em Entrar e sincronizar. 4) Quando aparecer “dados remotos encontrados”, escolha baixar para trazer os dados existentes ou enviar para substituir os dados da nuvem pelos dados locais.

A conexão usa a chave pública definida em supabase-config.js. Chaves secretas ficam somente no servidor.
