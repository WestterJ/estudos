Opção alternativa: entrar com Google (OAuth)

O login por Google é opcional e exige configuração adicional no painel Supabase. A conexão tradicional acima continua disponível sem essa configuração.

Para habilitar essa opção: Authentication → Sign In / Providers → Google; depois configure a URL de retorno. Se você usa o HTML diretamente no computador (file://), prefira a conexão tradicional com e-mail e senha.

Como conectar: 1) Informe a URL e a chave pública do projeto Nutri. 2) Clique em Guardar configuração. 3) Digite o e-mail e a senha da conta do aplicativo e clique em Entrar e sincronizar. 4) Quando aparecer “dados remotos encontrados”, escolha baixar para trazer os dados existentes ou enviar para substituir os dados da nuvem pelos dados locais.

Use somente a chave pública (publishable/anon), nunca a chave secreta/service_role. A senha é a senha do usuário cadastrado no Supabase Auth, não a senha de acesso ao painel administrativo.
